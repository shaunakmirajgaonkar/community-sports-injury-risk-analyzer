# 🏟️ Community Sports Injury Risk Analyzer — SportShield Local

Privacy-conscious, local-first Streamlit platform for screening potential injury-risk patterns across community sports facilities using authorized surface, weather, usage, equipment-check and incident data.

## Features
- Explainable 0–100 injury-risk screening score
- Low / Moderate / High / Critical classification
- Surface-condition assessment
- Weather and environmental context
- Facility usage and capacity pressure
- Equipment and maintenance checks
- Incident and near-miss analytics
- Sport-level comparison
- Explainable risk-factor heatmap
- Facility priority queue
- Guided review recommendations
- Scenario planner
- CSV upload/export
- Local visual assets
- No external APIs
- Synthetic demonstration datasets

This is safety-planning decision support. It does not diagnose injuries, predict individual outcomes, establish causation, certify facility safety, or replace qualified professionals or applicable procedures.
